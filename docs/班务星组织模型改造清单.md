# 班务星组织模型改造清单（班级 → 多组织切换）

> 基于对 `back/prisma/schema.prisma`、`back/src/modules/classes/*`、`mobile/src` 的实际检查（2026-09-04）编写。
> 目标：把「班级」泛化为「组织」（班级/社团/学生会部门/兴趣小组），支持企业微信式组织切换。
> **核心决策：不动任何业务表和外键，`classes` 表即组织表，加 `org_type` 字段区分类型。** 现有全部业务代码（后端 service + 前端页面）无需改动 class_id 逻辑。

---

## 〇、为什么选"最小改动"方案

| 方案 | 做法 | 工作量 | 风险 |
| --- | --- | --- | --- |
| **A（推荐）** | `classes` 表加 `org_type` 等字段，`class_id` 语义泛化为组织 ID（字段名不变） | 2–3.5 天 | 低，现有代码零破坏 |
| B | 新建 `orgs` 表，重写全部外键和 service | 2–3 周 | 高，容易出回归 |

现有 schema 中 14 张业务表（activities / attendances / homeworks / messages / votes / materials / archives / finance_* / tasks / pomodoro_sessions / random_draw_records / committee_handovers / audit_logs / error_logs）全部通过 `class_id` 外键关联 `classes`。方案 A 让「组织」直接复用这一整套关系，**功能 100% 继承**。

---

## 一、数据库改造（0.5 天）

### 1.1 `back/prisma/schema.prisma` — classes 模型扩展

```prisma
model classes {
  id          String   @id @db.Char(36)
  name        String   @db.VarChar(100)
  code        String   @unique(map: "code") @db.VarChar(20)

  // ===== 新增字段（组织模型）=====
  org_type    String   @default("class") @db.VarChar(20)  // class | association | committee | club
  category    String?  @db.VarChar(50)                     // 社团分类：体育/文艺/学术/志愿…
  logo_url    String?  @db.VarChar(500)                    // 组织 logo
  description String?  @db.Text                            // 组织简介
  max_members Int?                                        // 人数上限（可选）

  // 以下全部保持不变
  grade               String?  @db.VarChar(20)
  major               String?  @db.VarChar(100)
  qr_code_url         String?  @db.Text
  creator_id          String   @db.Char(36)
  announcement        String?  @db.Text
  status              Boolean  @default(true)
  created_at          DateTime @default(now())
  updated_at          DateTime @default(now())
  // ...现有 relation 数组全部保留
}
```

### 1.2 执行迁移

```bash
cd back
npx prisma migrate dev --name add_org_type
npx prisma generate
```

**约束**：不删除任何字段、不改任何外键、不动 `class_members`（`role` 字段 VarChar(50) 已能存「社长/部长/干事」，`role_level` 枚举 owner/admin/member 直接复用）。

## 三、前端改造（1–1.5 天）

### 3.1 全局封装层 `mobile/src/common/utils/class.ts`（关键）

现有代码已封装，只需扩展：

```ts
export function getCurrentClassId(): string {
  return secureStorage.get<string>('currentClassId') || ''
}
export function setCurrentClassId(classId: string) {
  secureStorage.set('currentClassId', classId)
}

// ===== 新增：当前组织对象（含类型）=====
export interface OrgInfo {
  id: string
  name: string
  orgType: string   // class / association / committee / club
  roleLevel?: string
}

export function getCurrentOrg(): OrgInfo | null {
  return secureStorage.get<OrgInfo>('currentOrgInfo')
}
export function setCurrentOrg(org: OrgInfo) {
  secureStorage.set('currentOrgInfo', org)
}
```

> **决策**：storage key 保留 `currentClassId`（11 处使用点零改动），新增 `currentOrgInfo` 缓存组织类型用于 UI 文案。切换器切换时同时更新两个 key。

### 3.2 新增 `OrgSwitcher.vue`（首页顶部，核心组件）

```
┌─────────────────────────────────────┐
│ [组织logo] 软工2班 ▾    [＋ 新建/加入] │  ← OrgSwitcher
│           班级 · 班长                  │
└─────────────────────────────────────┘
        ▼ 点击展开组织列表
┌─────────────────────────────────────┐
│ ✓ 软工2班     班级 · 班长   3条待办   │
│   篮球社      社团 · 社长   1条待办   │
│   学生会文体部 部门 · 干事   2条待办   │
│ ────────────────────────────────    │
│ ＋ 创建组织 / 加入组织                │
└─────────────────────────────────────┘
```

实现要点：
- 数据源：`GET /classes/my`（返回全部组织 + orgType + 待办数）
- 切换：`setCurrentClassId(org.id)` + `setCurrentOrg(org)` + `uni.reLaunch('/pages/home/index')`
- 类型图标：class→`lucide:school`、association→`lucide:tent`、committee→`lucide:users`、club→`lucide:star`
- 点击空白处关闭；移动端弹出层从顶部滑下（参考企业微信）
- 挂载位置：`pages/home/index.vue` 顶部

### 3.3 创建组织页（改造 `pages/class/join-class.vue` 或新增）

- 现有页面同时承担"创建/加入"，加入类型选择器：
  - 单选：`班级 / 社团 / 学生会部门 / 兴趣小组`
  - 选"社团"时显示：分类（体育/文艺/学术/志愿…）+ 简介 + Logo（可选）
- 提交 `POST /classes` 带 `orgType/category`
- 创建成功 → `setCurrentOrg` → 进首页

### 3.4 文案与展示按 `orgType` 通用化

| 场景 | class | association/committee/club |
| --- | --- | --- |
| 首页组织卡片 | 班级 · 班长 | 社团 · 社长 / 部门 · 干事 |
| 通知/签到/投票/报名/档案 | 不变 | 不变（100% 复用） |
| 作业模块 | 显示 | 隐藏入口（社团没有"作业"，改推荐"任务看板+资料库"） |

| 班级档案 | 班级档案 | 组织档案（换届→换届/换届交接复用 `committee_handovers`） |

### 3.5 个人中心 `pages/settings/personal-center.vue`
