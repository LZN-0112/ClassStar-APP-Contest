# 校园班级事务智能管理助手 — 交互设计文稿

> 文档定位：基于产品核心功能体系，输出单一手机 APP 的完整页面层级、页面清单与页面跳转关系，用于指导后续原型设计与开发。

---

## 一、设计概述

### 1.1 产品形态
- **单一手机 APP**：学生与班委共用同一个 APP，通过登录时的身份选择与角色分配区分功能权限。
- **入口分流**：登录后先选择「学生」或「班委」身份；选择「班委」后，进一步选择具体班委角色。
- **去群聊化**：将班级通知、签到、作业、活动、班费、资料等事务从微信群中抽离，按事务类型分类聚合，避免群消息刷屏和多人协作混乱。

### 1.2 设计原则
1. **一应用多角色**：一个 APP 覆盖所有角色，通过权限控制动态渲染功能入口。
2. **首页差异化**：学生首页侧重「查看与参与」；班委工作台首页侧重「管理与发布」。
3. **权限驱动**：不同班委角色分管不同功能模块，普通学生仅保留查看、提交、报名等参与类操作。
4. **去群聊化**：替代微信群的多人协作场景，按事务类型聚合信息，减少信息噪音。
5. **界面精简**：每个页面只保留当前角色最常用的功能，隐藏低频操作，降低认知负担。
6. **数据闭环**：考勤、作业、活动、班费数据自动汇总，学期末一键生成报表与班级档案。

### 1.3 登录与角色选择流程

```
启动页
    ↓
登录 / 注册 / 身份认证
    ↓
身份选择页
    ├─ 选择「学生」
    │       ↓
    │   加入班级
    │       ↓
    │   学生首页
    │
    └─ 选择「班委」
            ↓
        班委角色选择页
            ↓
        选择具体角色
            ├─ 固定角色：班长 / 团支书 / 学习委员
            ├─ 可选角色：副班长 / 生活委员 / 体育委员
            └─ 自定义角色：由学校/班级自行添加
            ↓
        创建班级 / 加入班级 / 导入学生名单 / 权限申请审核
            ↓
        班委工作台
```

## 四、页面跳转关系

### 4.1 全局跳转

| 起始页面 | 操作 | 目标页面 | 说明 |
|---------|------|---------|------|
| 启动页 | 自动跳转 | 登录页 / 首页 | 未登录→登录；已登录→首页/工作台 |
| 登录页 | 登录成功 | 身份选择页 | 首次使用需选择身份 |
| 身份选择页 | 选择「班委」 | 班委角色选择页 | 进一步选择具体班委角色 |
| 身份选择页 | 选择「学生」 | 加入班级页 | 学生直接加入班级 |
| 班委角色选择页 | 选择角色 | 创建/加入班级页 | 班委创建或加入班级 |
| 创建班级页 | 点击「导入学生名单」 | 导入学生名单页 | 支持 Excel / 教务系统 / QQ / 微信导入 |
| 创建/加入班级 | 完成 | 首页/工作台 | 进入主界面 |

## 五、核心流程设计

### 5.1 登录与身份选择流程

```
启动页
    ↓
登录 / 注册页
    ↓
身份选择页：学生 / 班委
    │
    ├─ 学生
    │   ↓
    │ 加入班级
    │   ↓
    │ 学生首页
    │
    └─ 班委
        ↓
    班委角色选择页
        ↓
    选择具体角色
        ├─ 固定角色：班长 / 团支书 / 学习委员
        ├─ 可选角色：副班长 / 生活委员 / 体育委员
        └─ 自定义角色
        ↓
    创建班级 / 加入班级 / 导入学生名单 / 权限审核
        ↓
    班委工作台
```

### 5.2 发布通知流程

```
班委工作台 → 发布通知
    → 编辑标题与正文（支持文字 / 附件 / 图片）
    → 设置时间 / 地点（地点可选，突出展示）
    → 选择接收范围（全班 / 指定分组 / 指定人员）
    → 是否开启「签字确认」
    → 设置再次提醒（发布后 X 分钟 / 小时再次提醒未读人员）
    → 发布成功
    → 返回通知列表 / 查看通知统计
```

### 5.3 通知查看与统计流程

```
学生：消息首页 → 通知详情
    → 顶部突出显示：时间、地点
    → 查看正文与附件
    → 签字确认（如开启）

班委：消息首页 → 通知详情 → 通知统计
    → 查看已读 / 未读人员列表
    → 查看签字确认凭证
    → 一键提醒未读人员
    → 设置 / 修改再次提醒时间
```

### 5.4 导入学生名单流程

```
创建班级 / 成员管理 → 导入学生名单
    → 选择导入方式
        ├─ Excel 导入：上传含学号、姓名、班级的表格
        ├─ 教务系统导入：授权后同步学校学生名单
        ├─ QQ 群导入：授权读取群成员并匹配
        └─ 微信群导入：授权读取群成员并匹配
    → 系统自动去重、匹配学号姓名
    → 人工确认与补全
    → 导入成功，生成班级成员列表
```

### 5.5 发起签到流程

```
班委工作台 → 发起签到
    → 选择签到方式
        ├─ 定位签到：划定教室地理范围
        ├─ 二维码签到：生成动态二维码
        ├─ 水印拍照签到：学生拍照并带水印
        └─ 口令签到：设置签到口令
    → 设置签到时间、课程关联
    → 发布签到
    → 进入考勤详情实时查看已签/未签
    → 一键催签 / 导出考勤报表
```

### 5.6 学生签到流程

```
学生首页 → 今日签到
    → 考勤列表
    → 签到页面
    → 定位 / 扫码 / 拍照 / 口令签到
    → 签到成功
```

### 5.7 发布作业流程

```
班委工作台 → 发布作业
    → 选择课程 / 输入作业名称
    → 设置截止时间
    → 设置文件命名规则（默认「学号-姓名」）
    → 发布作业
    → 进入作业详情查看提交进度
    → 一键催交 / 批量导出压缩包
```

### 5.8 学生提交作业流程

```
学生首页 → 待交作业

    → 作业提交
```

```
    → 上传票据凭证
    → 提交记账
    → 账本实时更新 / 生成收支报表
```

### 5.10 活动报名流程

## 六、界面精简设计原则

### 6.1 学生首页精简
- **顶部**：班级名称 + 待办提醒数量。
- **中部**：5 个核心快捷入口（通知、签到、作业、活动、资料）。
- **底部**：班级动态流，按时间线聚合通知、签到、作业、活动，替代微信群刷屏。
- **隐藏**：所有管理类入口、数据看板、班级设置等班委功能对学生不可见。

### 6.2 班委工作台精简
- **顶部**：今日待办（未读通知、待审批请假、待交作业提醒）。
- **中部**：5 个高频快捷入口（发布通知、发起签到、发布作业、班费记账、发布活动）。
- **底部**：今日数据概览（签到率、作业提交率、活动报名人数、班费结余）。
- **隐藏**：低频管理功能放入「班级」和「数据」Tab，避免工作台臃肿。

### 6.3 通知详情页精简
- **顶部**：通知标题 + 发布时间。
- **信息卡**：时间、地点（如有）突出展示，一眼可见。
- **正文区**：简洁正文 + 附件/图片。
- **操作区**：根据角色显示「签字确认」（学生）或「查看统计」（班委）。
- **去除**：与通知无关的评论、点赞等社交功能，保持事务属性。

### 6.4 消息首页精简
- 仅保留两个 Tab：**通知** 和 **互动**。
- 通知按时间倒序排列，已读/未读状态清晰标识。
- 支持按类型筛选（全部 / 通知 / 签到 / 作业 / 活动）。
