- **修复建议**：将 `eslint.config.js` 迁移为 flat config，或恢复为 `.eslintrc.js` 并删除 `eslint.config.js`。
- **涉及文件**：`back/eslint.config.js`

## 四、发现的问题与优先级排序

### 🔴 P0 — 严重

#### 1. 普通班级成员可创建班级（权限控制缺失）

| 属性 | 内容 |
|------|------|
| **严重程度** | 严重 |
| **模块** | 班级管理 |
| **涉及接口** | `POST /api/v1/classes` |
| **涉及文件** | `back/src/modules/classes/classes.controller.ts` |
| **实际结果** | 普通成员（role_level = member）使用有效 Token 调用 `POST /classes`，返回 200 并成功创建班级 |
| **预期结果** | 应返回 403，仅允许班长/班委/管理员创建班级 |
| **复现步骤** | 1. 使用成员账号登录；2. 获取 CSRF Token；3. 调用 `POST /api/v1/classes` 并传入 `{name, grade, major}`；4. 观察返回 200 与新班级 ID |
| **原因分析** | `ClassesController.createClass` 仅使用 `@UseGuards(JwtAuthGuard)` 验证登录，未添加 `@AdminOrOwner()` 等角色装饰器，也未在 Service 层校验用户角色 |
| **修复建议** | 在 `createClass` 方法上添加 `@AdminOrOwner()` 或自定义角色守卫，确保仅班级管理员/班委可创建班级 |

## 五、已修复的脚本问题（测试脚本自身）

在运行过程中，`back/tmp-comprehensive-test.ps1` 暴露出以下与 DTO 字段不匹配的问题，已在测试脚本中修正，未修改业务源码：

| 问题 | 原因 | 修复方式 |
|------|------|----------|
| 用户注册返回 400 | 请求体包含 DTO 不存在的 `role` 字段 | 移除 `role` |
| 创建班级返回 400 | 请求体包含 DTO 不存在的 `description` 字段 | 改为 `major` |
| 成员加入班级失败 | 使用 `inviteCode` 而非 `code` | 改为 `code`，并从 `classDetail.data.code` 读取 |
| 发布通知返回 400 | 缺少必填 `type` 字段 | 添加 `type: "notice"` |
| 发布作业返回 400 | 缺少必填 `subject` 字段 | 添加 `subject: "Math"` |
| 创建投票返回 400 | 使用 `endTime` 与对象数组 `options` | 改为 `deadline` 与字符串数组 `options` |
| 创建抽签返回 400 | 使用 `drawCount` | 改为 `mainCount` 与 `backupCount` |
| 结果文件保存失败 | 中文绝对路径在 `Out-File` 中出现编码截断 | 使用 `Join-Path $PSScriptRoot` + `[System.IO.File]::WriteAllText` |

## 六、测试结论与建议

1. **核心业务流程基本可用**：认证、班级、通知、作业、投票、抽签等 25 项功能测试通过，前后端数据交互一致。
2. **权限控制存在缺口**：普通成员可创建班级是本次检查中最严重的安全问题，需立即修复。
3. **代码质量工具需修复**：ESLint 配置失效导致无法执行静态分析，建议优先恢复。
4. **依赖安全需治理**：前后端均存在高危漏洞，建议建立定期审计机制。
5. **建议补充的测试**：
   - 密码重置完整流程（邮件/短信模拟）。
   - 学生名单 Excel 导入（文件大小、格式、非法后缀边界）。
   - 移动端真机或浏览器兼容性测试（TabBar 安全区域、首屏渲染）。
   - 活动报名按钮在不同活动状态下的 UI/UX 回归测试（已生成独立报告）。
