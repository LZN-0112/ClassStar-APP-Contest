## 1. 快速入门

## 2. 认证与账号管理

### 2.1 注册账号

**操作步骤：**

1. 打开 App，点击「注册」
2. 输入手机号，获取短信验证码
3. 填写姓名、学号（可选）、设置密码
4. 阅读并同意《用户协议》和《隐私政策》
5. 点击「注册」完成

**密码要求：**

- 长度：8-20 位

- 必须同时包含字母和数字

- 区分大小写

**注意事项：**

- 注册成功后不会自动登录，需返回登录页重新登录

- 手机号已注册则提示直接登录

### 2.2 登录

**密码登录：**

1. 输入手机号和密码
2. 点击「登录」

**验证码登录：**

1. 输入手机号
2. 获取短信验证码
3. 输入验证码后自动登录

**安全机制：**

- 连续 5 次密码错误，账号锁定 15 分钟

- Token 有效期 2 小时，过期需重新登录

- 支持设备绑定，异常登录会触发验证

### 2.3 重置密码

1. 在登录页点击「忘记密码」
2. 输入注册手机号
3. 获取并输入短信验证码
4. 设置新密码
5. 返回登录页使用新密码登录

### 2.4 加入班级

**方式一：输入班级码**

1. 登录后进入「加入班级」页面
2. 输入 6-8 位班级码
3. 点击「加入」

**方式二：扫描二维码**

1. 点击「扫码加入」
2. 对准班级二维码扫描
3. 确认加入

## 3. 班级管理

### 3.1 班级首页

**功能入口：**

| 模块    | 功能            |
| ----- | ------------- |
| 班级信息卡 | 班级名称、班级码、成员数  |
| 快捷入口  | 通知、作业、考勤、活动   |
| 班级公告  | 查看最新公告        |
| 待办提醒  | 未读通知、待交作业、待签到 |

### 3.2 成员列表

**查看成员：**

1. 进入「班级」→「成员列表」
2. 支持按姓名、学号搜索
3. 可按角色筛选（班委/普通成员）

**成员详情：**

- 点击成员头像进入详情页

- 查看个人信息、考勤记录、作业提交情况

- 班委可查看缴费记录

### 3.3 班委管理（仅管理员/班长）

**添加班委：**

1. 进入「班级设置」→「班委管理」
2. 点击「添加班委」
3. 选择成员，分配角色
4. 确认添加

**移除班委：**

1. 在班委列表中找到目标成员
2. 点击「移除」
3. 确认操作

**班委交接：**

1. 进入「班委交接」页面
2. 选择交接角色
3. 选择接任成员
4. 确认交接，系统记录交接日志

### 3.4 导入学生名单（班委功能）

**Excel 导入：**

1. 进入「导入学生」页面
2. 选择「Excel 导入」
3. 上传 .xlsx 或 .xls 文件
4. 系统自动解析学号、姓名、手机号
5. 确认导入

**文本导入（QQ/微信群）：**

1. 选择「文本导入」
2. 粘贴群成员文本（格式：学号 姓名 或 姓名）
3. 系统解析并预览
4. 确认导入

**导入规则：**

- 根据学号/手机号去重

- 已存在用户自动关联

- 不存在用户创建占位账号

### 3.5 班级设置（班委功能）

**可设置项：**

- 班级公告

- 班级头像

- 班级名称（需审核）

## 4. 通知消息

### 4.1 查看通知

**通知列表：**

1. 进入「消息」页面
2. 按类型筛选：通知/作业/活动
3. 未读通知标有红点

**通知详情：**

- 查看标题、内容、时间、地点

- 需签收的通知显示「签收」按钮

- 点击「签收」完成确认

### 4.2 发布通知（班委功能）

**操作步骤：**

1. 进入「发布通知」页面
2. 填写通知标题
3. 选择通知类型（通知/作业/活动）
4. 编辑通知内容
5. 设置时间、地点（可选）
6. 开启「需要签收」（可选）
7. 设置「再次提醒间隔」（可选）
8. 指定接收人（默认全班）
9. 添加附件（可选）
10. 点击「发布」

**签收功能：**

- 开启后，成员需点击「签收」确认

- 班委可查看已签收/未签收名单

- 支持导出签收名单 Excel

**再次提醒：**

- 设置间隔时间（如 30 分钟）

- 系统自动向未读成员发送提醒

- 也可手动触发立即提醒

### 4.3 消息统计（班委功能）

**查看统计：**

1. 进入「消息统计」页面
2. 选择目标通知
3. 查看数据：

   - 总人数、已读人数、未读人数

   - 已签收人数、未签收人数

   - 已读/未读名单

   - 已签收/未签收名单

**导出功能：**

- 点击「导出签收名单」

- 下载 Excel 文件

## 5. 作业管理

### 5.1 查看作业列表

**学生视角：**

- 查看班级所有作业

- 按状态筛选：进行中/已截止

- 显示截止时间、提交状态

**班委视角：**

- 额外显示「离线核对」入口

- 可查看提交统计

### 5.2 提交作业

**操作步骤：**

1. 进入作业详情
2. 点击「提交作业」
3. 填写作业内容（文字）
4. 上传附件（图片/文档）
5. 点击「提交」

**注意事项：**

- 截止前可重复提交，以最后一次为准

- 截止后无法提交（除非申请延时）

### 5.3 我的作业

**状态说明：**

| 状态  | 说明         |
| --- | ---------- |
| 待提交 | 未提交且未逾期    |
| 已提交 | 已提交作业      |
| 已逾期 | 未提交且已过截止时间 |

**操作：**

- 待提交：点击「去提交」

- 已提交：查看提交内容、修改（截止前）

- 已逾期：无法提交，显示红色标记

### 5.4 申请延时（学生功能）

**操作步骤：**

1. 进入作业详情
2. 点击「申请延时」
3. 填写申请理由
4. 选择期望延长时间
5. 提交申请

**审批流程：**

- 班委收到延时申请通知

- 班委审批通过/拒绝

- 学生收到审批结果通知

### 5.5 发布作业（班委功能）

**操作步骤：**

1. 进入「发布作业」页面
2. 填写作业标题
3. 选择科目（可选）
4. 编辑作业内容
5. 设置截止时间
6. 添加附件（可选）
7. 点击「发布」

**作业状态自动计算：**

- 当前时间 < 截止时间：进行中

- 当前时间 ≥ 截止时间：已截止

### 5.6 离线核对（班委功能）

**适用场景：**

- 线下收集作业后，与系统名单核对

- 识别未提交学生

**方式一：批量核对**

1. 进入「离线核对」→「批量核对」
2. 选择作业
3. 勾选已交作业的学生
4. 点击「确认」
5. 系统生成已交/未交名单

**方式二：截图核对（OCR）**

1. 进入「离线核对」→「截图核对」
2. 选择作业
3. 上传名单截图（如学习通截图）
4. 系统 OCR 识别学号/姓名
5. 核对识别结果
6. 确认生成名单

**核对结果：**

- 已交名单

- 未交名单

- 支持导出 Excel

## 6. 考勤签到

### 6.1 查看考勤列表

**学生视角：**

- 查看班级考勤记录

- 显示考勤状态：未开始/进行中/已结束

- 显示签到状态：已签到/未签到/迟到/请假

### 6.2 签到

**签到方式：**

**二维码签到：**

1. 进入「签到」页面
2. 点击「扫码签到」
3. 扫描班委展示的二维码
4. 签到成功

**定位签到：**

1. 进入「签到」页面
2. 点击「定位签到」
3. 系统获取当前位置
4. 在签到范围内则成功

**手动签到：**

1. 进入「签到」页面
2. 点击「签到」按钮
3. 签到成功

**注意事项：**

- 签到有时间范围限制

- 定位签到需在指定范围内

- 迟到会标记「迟到」状态

### 6.3 发布考勤（班委功能）

**操作步骤：**

1. 进入「发布考勤」页面
2. 填写考勤标题
3. 选择签到方式（二维码/定位/手动）
4. 设置开始时间、结束时间
5. 设置签到地点（定位签到时）
6. 设置签到范围（如 100 米）
7. 点击「发布」

**考勤进行中：**

- 查看已签到人数

- 查看签到名单

- 可提前结束考勤

### 6.4 请假申请

**操作步骤：**

1. 进入「请假申请」页面
2. 选择请假类型（事假/病假/其他）
3. 填写请假理由
4. 选择开始时间、结束时间
5. 上传证明材料（可选）
6. 提交申请

**审批流程：**

- 班委收到请假申请

- 班委审批通过/拒绝

- 学生收到审批结果

### 6.5 请假审批（班委功能）

**操作步骤：**

1. 进入「请假审批」页面
2. 查看待审批列表
3. 点击申请查看详情
4. 审批通过/拒绝
5. 填写审批意见（可选）

### 6.6 考勤报告

**查看报告：**

1. 进入「考勤报告」页面
2. 查看整体数据：

   - 总考勤次数

   - 出勤率

   - 迟到次数

   - 请假次数
3. 查看明细列表
4. 支持导出 Excel

## 11. 实用工具

### 11.1 番茄钟

**功能：**

- 专注学习计时

- 25 分钟工作 + 5 分钟休息

- 统计专注时长

**使用方法：**

1. 进入「番茄钟」
2. 点击「开始」
3. 专注 25 分钟
4. 休息 5 分钟
5. 循环进行

### 11.2 随机抽签

**功能：**

- 课堂提问随机抽人

- 活动分组随机抽签

- 支持排除人员

- 支持预览确认

3. 点击「排除人员」（可选）
4. 选择要排除的成员
5. 点击「开始抽签」
6. 预览抽签结果
7. 点击「重新抽签」或「确认保存」

**排除人员：**

- 点击「排除人员」按钮

- 勾选要排除的成员

- 点击「确定」

- 候选人池自动减少

**抽签记录：**

- 查看历史抽签记录

- 查看抽签详情

- 班委可作废抽签

### 11.3 扫码

**功能：**

- 扫描班级二维码加入班级

- 扫描签到二维码签到

**使用方法：**

1. 点击「扫码」
2. 对准二维码
3. 自动识别并执行操作

### 12.2 账户安全

**功能：**

## 13. 常见问题

### Q1: 忘记密码怎么办？

**A:** 在登录页点击「忘记密码」，通过手机验证码重置密码。

### Q2: 如何加入班级？

**A:** 两种方式：

1. 输入班级码（6-8 位数字）
2. 扫描班级二维码

### Q3: 作业截止后还能提交吗？

**A:** 不能。截止后无法提交，除非申请延时并通过审批。

### Q4: 签到失败怎么办？

**A:**

- 检查网络连接

- 确认在签到范围内（定位签到）

- 联系班委手动补签

### Q5: 如何查看已签收通知？

**A:** 进入「消息」→「消息统计」，选择通知查看签收情况。

### Q6: 班委如何导出名单？

**A:** 在对应功能页面（通知签收、作业提交、活动报名等）点击「导出」按钮，下载 Excel 文件。

### Q7: 如何申请请假？

**A:** 进入「考勤」→「请假申请」，填写请假信息并提交，等待班委审批。

### Q8: 随机抽签如何排除人员？

**A:** 点击「排除人员」按钮，勾选要排除的成员，确认后候选人池自动减少。

### Q9: 如何修改个人信息？

**A:** 进入「我的」→「个人信息」，点击头像或姓名修改（部分信息需审核）。

### Q10: 如何联系技术支持？

**A:** 进入「我的」→「帮助与反馈」→「联系客服」。
