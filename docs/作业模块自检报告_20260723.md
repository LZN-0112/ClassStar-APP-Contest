## 一、问题诊断与修复

### 问题：点击"一键通知提醒未交同学"后显示错误

**根因**：`CheckResult.tsx`（核对结果页）的 `handleRemind` 函数仅是一个 `alert()` mock，未接入真实后端 API。同时页面使用 `location.state` 传递参数，页面刷新后数据丢失。

**涉及文件**：
- [front/src/pages/homeworks/CheckResult.tsx](file:///e:/校园班级事务智能管理助手/front/src/pages/homeworks/CheckResult.tsx)
- [front/src/App.tsx](file:///e:/校园班级事务智能管理助手/front/src/App.tsx)
- [front/src/pages/homeworks/BatchCheck.tsx](file:///e:/校园班级事务智能管理助手/front/src/pages/homeworks/BatchCheck.tsx)
- [front/src/pages/homeworks/ScreenshotCheck.tsx](file:///e:/校园班级事务智能管理助手/front/src/pages/homeworks/ScreenshotCheck.tsx)
- [front/src/pages/homeworks/OfflineCheckHome.tsx](file:///e:/校园班级事务智能管理助手/front/src/pages/homeworks/OfflineCheckHome.tsx)

**修复内容**：

| 修复项 | 说明 |
|--------|------|
| `CheckResult.tsx` | `handleRemind` 接入真实 API：调用 `POST /classes/:classId/messages` 创建催交通知，类型 `type: 'homework'` |
| `CheckResult.tsx` | 路由改为 `/check-result/:homeworkId` + `?homeworkTitle=xxx` 查询参数，使用 `useParams` + `useSearchParams` 替代 `location.state` |
| `CheckResult.tsx` | 从后端 API 获取真实提交数据（`GET /classes/:classId/homeworks/:id`）和班级成员（`GET /classes/:classId/members`），替代 mock 数据 |
| `CheckResult.tsx` | 添加 loading 状态、催签中 loading 动画、错误 toast 提示 |
| `App.tsx` | 新增路由 `/check-result/:homeworkId` |
| `BatchCheck.tsx` | 跳转改为 URL 参数方式 |
| `ScreenshotCheck.tsx` | 跳转改为 URL 参数方式 |
| `OfflineCheckHome.tsx` | 跳转改为 URL 参数方式 |
| `MessageStats.tsx` | 修复 `useLocation` 未导入导致的 TypeScript 编译错误（上一轮遗留） |
