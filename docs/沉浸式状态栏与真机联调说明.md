# 沉浸式状态栏与真机联调说明

> 目标：App 达到微信/抖音式沉浸式——顶部只显示手机系统状态栏，内容从屏幕最顶开始，无重复状态栏、无白条、无空隙，返回按钮/标题紧贴且避让系统状态栏。H5/浏览器预览保持原样（保留手机壳 + 模拟状态栏）。

## 涉及文件

### 原生（Capacitor / Android）
| 文件 | 改动 |
|---|---|
| `front/android/.../MainActivity.java` | `EdgeToEdge.enable` **移到 `super.onCreate` 之后**（避免被 Capacitor 覆盖回默认状态栏）；`AndroidBridge.getStatusBarHeight()` 改用 `getRootWindowInsets().getInsets(WindowInsets.Type.statusBars()).top`（比 `status_bar_height` dimen 更可靠）；`WebView.setFitsSystemWindows(false)`、`padding/margin=0` |
| `front/android/.../res/values/styles.xml` | `AppTheme` 由 `Theme.AppCompat.Light.DarkActionBar` 改为 **`Theme.AppCompat.DayNight.NoActionBar`**（去掉原生标题栏“班务星”白条） |
| `front/capacitor.config.json` | `android.adjustMarginsForEdgeToEdge` 设为 `disable`（Web 层用 `--safe-top` 自行避让） |
| `front/android/.../res/xml/network_security_config.xml` | 为局域网后端 IP 放行明文 HTTP（真机联调用） |

### Web（`front`）
| 文件 | 改动 |
|---|---|
| `src/lib/capacitor.ts` | `isNative`；`initStatusBar()`：加 `is-native` 类、`setOverlaysWebView({overlay:true})`、`setBackgroundColor('#00000000')`（状态栏透明）、`setStyle`；**状态栏高度换算成 CSS 像素**写入 `--safe-top`；`setStatusBarStyle(light)` 切换图标深浅 |
| `src/index.css` | `html.is-native [data-pencil-name="Status Bar"], ... div[class*="h-[62px]"][class*="justify-between"][class*="items-center"]` 设为**高度=`--safe-top` 的透明安全占位**（把 header 推到状态栏之下、统一避让） |
| `src/App.tsx` | App 挂载后 `useEffect` 调 `initStatusBar()`（确保 AndroidBridge 已注入再读高度） |
| `src/hooks/useStatusBarStyle.ts` | 按页面背景切换状态栏图标深/浅色 |
| `src/components/layout/StatusBar.tsx` | `isNative` 时返回 `null`（真机不渲染模拟状态栏） |
| `src/components/layout/UnifiedHeader.tsx` | 头部背景顶到最上；内容区 `paddingTop = var(--safe-top)+4px` 避让；标题上移进深色渐变区；`useStatusBarStyle(true)`（白字） |
| `src/pages/home/StudentHome.tsx` | 首页隐藏模拟状态栏、Header 背景顶到最上、`paddingTop = var(--safe-top)+12px`、`useStatusBarStyle(false)`（浅色背景深字） |
| `src/pages/settings/PersonalCenter.tsx` | 顶部返回/设置容器加 `paddingTop = var(--safe-top)` 避让 |
| `index.html` | viewport 加 `viewport-fit=cover` |

## 关键点
1. **`--safe-top` 必须用 CSS 像素**：`AndroidBridge.getStatusBarHeight()` 返回的是**物理像素**（本机实测 520dpi 下状态栏 = 150px），需 `除以 window.devicePixelRatio`（≈3.25）换算成 ≈46 CSS px。否则顶部避让会被放大约 3 倍、整体下移。
2. **统一避让机制**：所有页面的模拟状态栏块在真机下变成一个 `--safe-top` 高的透明占位，把其下的 header/返回按钮统一推到状态栏下方。
3. **H5 预览不受影响**：`isNative=false` 时仍渲染模拟状态栏 + 手机壳。

## 真机打包/调试
```bash
cd front && npm run build && npx cap sync android
cd android && ./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
# 调试 WebView（MainActivity 已开 setWebContentsDebuggingEnabled）：
adb forward tcp:9222 localabstract:webview_devtools_remote_<pid>
# Chrome 打开 chrome://inspect 远程调试
```

## 真机联调数据
- `.env.production`：`VITE_API_BASE_URL=http://<电脑局域网IP>:3000/api/v1`
- `network_security_config.xml` 已为该 IP 放行明文 HTTP；后端需监听 `0.0.0.0` 且防火墙放行 3000。
