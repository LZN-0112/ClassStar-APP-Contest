- `POST /classes/:id/members/:userId/profile`：body `{ realName?: string, studentId?: string }`

## 九、最小验收路径（P0 冒烟）

1. 新手机号注册（填真实姓名 + 昵称）→ 查库确认 `users.name` 正确
2. 加入 A 班：姓名一致 → 已确认；换账号姓名不一致 → 待确认
3. 新账号加入 B 班 → 未核实
4. 班委在成员列表一键确认待确认成员 → 详情页状态同步
5. 管理员修正某成员姓名学号 → 状态变已确认
6. 普通学生账号验证看不到任何确认/修正入口，直接调接口返回 403
