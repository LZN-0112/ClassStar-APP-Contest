确保以下功能从“开发状态”转变为“可正常运行状态”：

## 3. 测试方法

- **静态检查**：`vue-tsc --noEmit` 全量类型检查。
- **H5 真机模拟**：使用浏览器自动化在 390×844 等移动端视口下访问关键页面。
- **接口冒烟**：直接调用后端 `/api/v1/health` 确认服务可用。
- **用户路径模拟**：登录 → 身份选择 → 创建班级 → 首页 → 各功能列表页。
- **回归检查**：针对之前修复的 TabBar、状态映射、日期时间、H5 导航等问题进行复测。

## 5. 已修复问题清单

| 问题 | 影响页面/模块 | 修复方式 |
|------|--------------|----------|
| 通知发布页缺少 `AppIcon` 导入 | `notice/publish.vue` | 补充组件导入 |
| H5 datetime-local 缺少秒数导致后端校验失败 | `notice/publish.vue`、`activity/publish.vue` | 添加 `onH5EventTimeInput` / `onH5DeadlineInput` 补全 `:00` |
| 考勤“open”状态显示错误 | `attendance/list.vue`、`attendance/detail.vue` | 增加 `open` →“进行中”映射 |
| 作业“published”状态显示英文 | `homework/list.vue` | 增加 `homeworkStatusMap` 中文映射 |
| TabBar 定位偏移 | `components/TabBar.vue` | 使用 `left:0; right:0; margin:0 auto` 替代 `transform:translateX(-50%)` |
| H5 端 TabBar 重复渲染 | `App.vue`、`main.ts` | H5 通过 `main.ts` 单独挂载，App.vue 条件编译排除 |
| 个人中心出现滚动条 | `settings/personal-center.vue` | 去除右侧滚动条 |
| 后端 `message_reads.groupBy` 查询条件错误 | `back/messages.service.ts` | 修正查询条件 |
| Redis 连接失败导致后端启动失败 | `back` RedisService | 实现内存缓存降级 |
| 股票模拟定时器类型错误 | `stock/index.vue` | 使用 `ReturnType<typeof setInterval>` 统一类型 |

## 6. 仍存在的非阻塞性问题

| 问题 | 说明 | 建议 |
|------|------|------|
| `uni-stat` 第三方统计请求 `ERR_ABORTED` | 开发环境下 DCloud 统计域名无法访问，属于外部网络问题 | 生产环境或打包后可配置关闭统计 |
