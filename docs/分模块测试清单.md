| 属性 | 内容 |
|------|------|
| 检查项 | 文件上传大小限制 |
| 结果 | 失败 |
| 复现步骤 | 登录后调用 `POST /api/v1/classes/{classId}/students/import`，上传 11MB xlsx 文件 |
| 实际结果 | status=201，文件被接受并导入 |
| 预期结果 | status=400 或 413，提示文件超过大小限制 |
| 涉及接口 | `POST /api/v1/classes/{classId}/students/import` |
| 涉及文件 | `back/src/modules/classes/classes.controller.ts`、`classes.service.ts` |
| 风险等级 | 中 |
| 修复建议 | 后端增加文件大小二次校验；建议与前端限制保持一致 |
