```text
【任务】补全组织模型缺失功能，共 4 项。只改列出的文件。

1. 后端新增"退出组织"接口（back/src/modules/classes/）：
   - controller 增加 @Post(':id/leave')，service 增加 leaveClass(id, userId)
   - 逻辑：
     a. 校验用户是该组织成员，否则抛 NotFoundException
     b. 若用户是 owner（role_level='owner'），拒绝退出，提示"组织创建者不能退出，请先转让"
     c. 删除 class_members 记录
   - 若用户退出后是当前页面所在组织，前端负责跳转（见第 2 项）

2. 前端个人中心增加"我的组织"管理（mobile/src/pages/settings/personal-center.vue）：
   - 展示当前用户加入的全部组织：名称 + 类型徽标 + 我的角色 + 成员数
   - 每项操作：切换进入（reLaunch 到首页）、退出（弹确认框 → 调 leave 接口 → 刷新列表；若退出的是当前组织，退出后切到剩余第一个组织或回加入页）
   - 数据源复用 getMyClasses()（auth.ts 已有）

3. 待办聚合排除发布者（back/src/modules/classes/classes.service.ts 的 getOrgTodos）：
   - 待签收通知查询增加条件：publisher_id: { not: userId }
   - 即：自己发布的通知不进入自己的待办

4. 若决定补齐移动端档案页（可选，由我确认后再做）：
   - mobile/src/pages/class/archive.vue 从占位改为调后端 archives 接口（参考 back 的 archives 模块已有接口）
   - 否则保持占位不动

【约束】只改上述文件；不引入新依赖；leave 接口必须校验成员身份与 owner 保护；前端退出当前组织后必须正确跳转，不能停留在已退出的组织页面。
【验收】npx tsc --noEmit（back）与前端编译通过；H5 验证：非 owner 能退出、owner 退出被拒、退出当前组织后自动切换。
```

## 三、全功能测试清单（手动执行，H5 端）

- 账号 B（成员）：加入"软件2201班" + "篮球社" + 用邀请码加入一个"部门"

### A. 组织创建与加入
