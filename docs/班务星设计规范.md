## 1. 文档说明

本文档从 `front/` 源码（`tailwind.config.js`、`src/index.css`、`src/components/`、`src/pages/`）中提取设计系统规范，所有色值、字号、间距、圆角、阴影数值均与源码一致。

**设计基调**：移动端优先（Mobile First），桌面端以 393×844px 手机外框居中演示。主色为品牌蓝 `#0062FF`，整体风格简洁现代，卡片化布局，圆角柔和，阴影轻量。

## 4. 间距系统

### 4.1 基础单位

Tailwind 默认 **4px** 基准单位（1 = 0.25rem = 4px）。

### 4.2 常用间距值

| Token | rem | px | 用途 |
|-------|-----|----|------|
| 0.5 | 0.125rem | 2px | 极小组件内间距 |
| 1 | 0.25rem | 4px | 图标与文字间距 |
| 1.5 | 0.375rem | 6px | 紧凑间距 |
| 2 | 0.5rem | 8px | 卡片内小间距 |
| 2.5 | 0.625rem | 10px | 卡片间距（统计卡片 gap） |
| 3 | 0.75rem | 12px | 图标容器间距 |
| 3.5 | 0.875rem | 14px | 按钮垂直内边距 |
| 4 | 1rem | 16px | 卡片内边距、页面水平边距 |
| 5 | 1.25rem | 20px | 页面水平/垂直边距 |
| 6 | 1.5rem | 24px | StatusBar 水平边距 |
| 8 | 2rem | 32px | 空状态上下边距 |
| 10 | 2.5rem | 40px | 返回按钮尺寸 |
| 12 | 3rem | 48px | 首页头像尺寸 |
| 14 | 3.5rem | 56px | 输入框高度 |
| 16 | 4rem | 64px | 弹窗内边距 |
| 18 | 4.5rem | 72px | 自定义大间距 |
| 20 | 5rem | 80px | 个人中心头像尺寸 |
| 22 | 5.5rem | 88px | 自定义大间距 |

### 4.3 关键间距规范

- **页面内容区水平边距**：`px-5`（20px）
- **页面内容区垂直边距**：`pt-4`（16px）、`pb-5`（20px）
- **卡片内边距**：`p-4`（16px）
- **卡片之间间距**：`gap-4`（16px）
- **一级页面底部安全区**：`pb-20`（80px，预留底部导航栏）
- **底部导航栏内边距**：`0.375rem 0 calc(0.375rem + env(safe-area-inset-bottom))`

## 7. 断点与响应式

### 7.1 Tailwind 默认断点

| 断点 | 阈值 | 用途 |
|------|------|------|
| `sm` | 640px | 桌面端切换（手机外框显示） |
| `md` | 768px | — |
| `lg` | 1024px | — |
| `xl` | 1280px | — |
| `2xl` | 1536px | — |

### 7.2 手机框架尺寸

| 属性 | 值 |
|------|-----|
| 桌面端演示宽度 | `393px` |
| 桌面端演示高度 | `844px` |
| 最大宽度 | `430px` |
| 圆角 | `40px`（`rounded-device`） |

**响应式行为**：
- 移动端（< 640px）：全宽铺满，高度 `100dvh`
- 桌面端（≥ 640px）：固定 393×844px 居中，带圆角和阴影

## 10. 交互动画规范

### 10.1 页面切换动画

**来源**：`components/common/PageTransition.tsx`（framer-motion）

| 属性 | 值 |
|------|-----|
| 入场 | opacity 0→1，x 20px→0 |
| 出场 | opacity 1→0，x 0→-20px |
| 时长 | `0.25s` |
| 缓动 | `[0.25, 0.1, 0.25, 1]`（ease-in-out） |

### 10.2 点击反馈

| 反馈类型 | 效果 | 适用 |
|----------|------|------|
| 缩放 | `active:scale-95` | 快捷入口、头像、扫码按钮 |
| 透明度 | `active:opacity-90` | 主按钮 |
| 透明度 | `active:opacity-70` | 返回按钮、文字链接、TabBar |
| 背景色 | `active:bg-slate-50` | 可点击卡片、列表项 |
| 背景色 | `active:bg #F8FAFC` | 快捷入口项 |

**过渡时长**：
- 缩放：`150ms`
- 颜色：`200ms`
- 透明度：默认

### 10.3 加载动画

| 动画 | 效果 |
|------|------|
| 旋转加载 | `animate-spin`（CSS 旋转） |
| 内联旋转 | `border-2 border-t-transparent rounded-full animate-spin` |

### 10.4 弹窗动画

| 元素 | 动画 |
|------|------|
| 遮罩层 | `fadeIn`（opacity 0→1） |
| 弹窗内容 | `slideUp`（translateY 100%→0）/ `slide-in-from-bottom` |

### 10.5 TabBar 图标动画

**来源**：`index.css` `@keyframes iconBounce`

- 时长：`0.45s`
- 缓动：`ease`
- 效果：选中时图标上下弹跳（`translateY` -0.3em → 0 → -0.1em → 0）

### 10.6 其他过渡

| 场景 | 过渡 |
|------|------|
| 问候语切换 | `opacity 0→1`，`duration-300` |
| 个人中心头部展开 | `transition-all duration-500 ease-in-out` |
| 进度条宽度 | `transition-[width] duration-500 ease-out` |
| 滚动行为 | `overscroll-y-contain` |

### 10.7 全局滚动

- 隐藏滚动条：`scrollbar-width: none`，`::-webkit-scrollbar { display: none }`
- `box-sizing: border-box`
- `overflow-x: hidden`
