# 提示词：删除班务星 mobile 端的 H5 构建（Web 端）

> 用途：交给 AI 编码工具（Trae / 豆包）或人工执行。目标是把 `mobile` 目录清理成只保留 **微信小程序（mp-weixin）** 与 **原生 App（app-plus）** 两个构建目标。

## 任务

删除 `E:\校园班级事务智能管理助手\mobile` 中所有 H5（网页版）相关内容。删除后必须保证：
1. 小程序构建不受影响；
2. App（app-plus）构建不受影响；
3. 页面、业务逻辑、后端接口全部不变。

## 背景（重要）

- 项目为 UniApp（Vue3 + Vite），根目录 `E:\校园班级事务智能管理助手`，本次只动 `mobile/` 子目录。
- 源码已在 GitHub 完整备份，可放心删除；但**构建产物 `dist/` 被 .gitignore 忽略、不在 GitHub 备份里**——它是可再生的构建输出，删了也无风险。
- `front/`（React Web 端）和 `back/`（NestJS 后端）与本任务无关，**严禁触碰**。

## 执行范围（四步，全部完成）

### 第 1 步：删除 H5 构建产物
- 删除目录 `mobile/dist/build/h5/`（存在则删，不存在跳过）。
- `mobile/dist/build/` 下其余内容（如 `mp-weixin/`）一律保留。

### 第 2 步：删除 H5 构建脚本
- 在 `mobile/package.json` 的 `scripts` 中删除两行：
  - `"dev:h5": "uni"`
  - `"build:h5": "uni build"`
- 其余脚本（`build:mp-weixin`、`dev:mp-weixin`、`typecheck`）原样保留。
- `dependencies` / `devDependencies` **一律不动**（含 `@dcloudio/uni-h5` 等，删除依赖可能破坏编译）。

### 第 3 步：删除 manifest 中的 H5 平台配置
- 在 `mobile/src/manifest.json` 中删除顶层 `"h5": { ... }` 配置段（含 `title`、`router.mode` 等子字段）。
- 保留 `app-plus`、`mp-weixin`、`vueVersion` 及其余字段；删除后 JSON 必须仍合法。

### 第 4 步：清理源码中的 `#ifdef H5` 条件编译块
- 全量搜索 `mobile/src` 下所有 `#ifdef H5` 块（含 `// #ifdef H5` 与 `<!-- #ifdef H5 -->` 两种写法），删除**每个 `#ifdef H5 ... #endif` 块内的全部代码及块注释本身**。
- 涉及文件（约 17 个，以实际 grep 结果为准）：
  `src/main.ts`、`src/App.vue`、`src/common/config/index.ts`、`src/common/api/request.ts`、`src/components/AppButton.vue`、`src/components/TabBar.vue`、`src/pages/material/upload.vue`、`src/pages/material/list.vue`、`src/pages/index/index.vue`、`src/pages/notice/detail.vue`、`src/pages/notice/publish.vue`、`src/pages/homework/publish.vue`、`src/pages/activity/publish.vue`、`src/pages/attendance/create.vue`、`src/pages/class/join-class.vue` 等。
- **收尾清理**：
  - 某处删完 `#ifdef H5` 后若只剩 `#ifndef H5 ... #endif` 包裹的代码，将外层 `#ifndef H5` 与 `#endif` 注释移除（保留中间代码原样），因为该代码对所有保留平台生效；
  - 删除后出现"仅 H5 使用"的 import / 变量 / 组件（如 `main.ts` 中的 `TabBar`、`createClientApp`），一并清理，避免未使用告警；
  - 保持代码风格、缩进与上下文一致。

## 红线（任何一条被触碰即视为失败，立即停止并说明）

1. **禁止删除 `#ifndef H5 ... #endif` 块内的代码**（那是小程序/App 的代码）。H5 分支删除后只允许解除外层 `#ifndef H5` 包裹注释，中间代码必须逐字保留。
2. **禁止删除或修改 `#ifdef APP-PLUS` / `#ifdef APP-PLUS || APP` 块**（App 端代码，如 `share-receiver.ts` 分享接收、`secure.ts` 安全存储）。
3. **禁止删除或修改 `mobile/src/pages/` 下任何页面文件**（79 个页面为小程序与 App 共用）。
4. **禁止修改 `mobile/src/pages.json`**（页面注册表，与 H5 无关）。
5. **禁止触碰 `front/` 与 `back/` 目录**（React Web 端、NestJS 后端）。
6. **禁止删除 `mobile/dist/` 下除 `build/h5` 以外的任何内容**（尤其 `build/mp-weixin`）。
7. **禁止修改 `package.json` 的依赖清单**（只允许删 `scripts` 里的两条 H5 命令）。
8. **禁止改动 `.gitignore`、`README`、`docs/`、`sql/`、根目录脚本等无关文件**。
9. **禁止执行任何 `git commit` / `git push` / `git reset`**——只做本地文件修改，版本管理由用户自行处理。

## 验证（完成后逐项检查，全部通过才算完成）

1. `grep -rn "ifdef H5" mobile/src` → 结果为空。
2. `mobile/package.json` 中不含 `build:h5` / `dev:h5`。
3. `mobile/src/manifest.json` 无 `"h5"` 段，且能被 JSON 解析器正常解析。
4. `mobile/dist/build/h5/` 目录不存在。
5. 在 `mobile/` 下执行 `npm run build:mp-weixin` → 构建成功、产物正常生成。
6. 抽查 3 个清理过 H5 块的源文件（建议 `main.ts`、`common/config/index.ts`、`pages/attendance/create.vue`），确认 `#ifndef H5` 块内代码完整保留、无语法错误、无未使用 import。
7. `grep -rn "uni-h5" mobile/package.json` → 依赖仍在（未误删）。

## 回滚预案

- 若中途触碰红线或验证失败：立即停止，说明已做的改动；用 git 还原相关文件（源码在 GitHub 有备份）。
- 建议分两阶段执行：先做第 1~3 步（低风险），验证通过后再做第 4 步源码清理（中风险）；每阶段结束向用户汇报。
